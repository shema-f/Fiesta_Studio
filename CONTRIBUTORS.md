### How to Be Listed
Every contributor who has a pull request merged into `main` is eligible to be listed here.
To add yourself:
1. Ensure your pull request includes a DCO sign-off (`Signed-off-by: Name <email>`).
2. Add your name, GitHub handle, and area of contribution to the list below in alphabetical order by handle.
3. Maintainers verify and merge during PR review.

### Recognition Policy
We recognize contributions of all types:
- **Code:** DSP, audio engine, UI components, state management, test suites.
- **Documentation:** Architectural docs, beginner guides, API specs, typos.
- **Sound Design:** CC0/royalty-free sample contributions with verified provenance.
- **Internationalization:** Translations into Kinyarwanda, Swahili, French, Spanish, etc.
- **Quality Assurance:** Reproducible audio bug reports, latency testing on diverse hardware.
